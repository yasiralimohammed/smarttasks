SmartTasks

A task management Android application developed using Kotlin and Jetpack Compose.

SmartTasks helps users create, organize and manage daily tasks with categories, due dates, reminders and notifications.

Features

  • Create and manage tasks
  • Organize tasks by category
  • Set due dates and times
  • Task reminder notifications
  • Mark tasks as completed
  • Local offline storage

Application Screenshots

Technologies Used

  • Kotlin for Android Development
  • Jetpack Compose for UI Development
  • Android Studio for Development Environment
  • SharedPreferences for Local Storage
  • Gson for JSON Parsing
